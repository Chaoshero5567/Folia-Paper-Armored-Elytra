# Folia-Paper-Armored-Elytra
A plugin that lets Folia/Paper servers combine Elytras and Chestplates, while keeping both textures




Note: The texture pack used is not my originall creation, i am using one from this Datapack: https://modrinth.com/project/oQQRBqCp!
So thx to the original creator!
